# twtodos

A focused, responsive todo list built with plain HTML, CSS, and JavaScript. It uses Bootstrap 5.3.8 from the official CDN and stores tasks in the browser's `localStorage`.

## Run

Open `index.html` directly in a browser, or use VS Code's Live Server extension if you already have it installed. No build or install step is required.

## Features

- Add, complete, and delete tasks
- Filter by all, open, or completed tasks
- Clear all completed tasks
- Persistent browser storage
- Responsive Bootstrap layout
